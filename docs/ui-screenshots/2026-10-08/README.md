# Скриншоты интерфейса Karavay

Снимки сделаны 8 октября 2026 года с текущей локальной базой данных.

- `desktop/` — монитор 1920×1080; длинные страницы сняты целиком.
- `mobile/` — телефон 390×844; длинные страницы сняты целиком.
- Модальные окна сняты в реальном размере экрана. Для длинной мобильной формы проверки веса есть отдельные верхний и нижний кадры `11` и `11b`.
- Всего: 84 PNG-файла — 41 десктопный и 43 мобильных.

## Карта экранов

### Общие экраны

- `01-login` — вход.
- `02-dashboard` — главная консоль.
- `03-mobile-navigation-right` — правая часть прокручиваемой мобильной навигации; только телефон.

### Файлы и создание объектов

- `04-files-root` — корень файловой структуры.
- `05-files-root-new-folder` — создание корневой папки.
- `06-files-workshop` — содержимое цеха: дерево, ингредиенты и события.
- `07-files-new-folder` — создание вложенной папки.
- `08-files-new-ingredient` — создание ингредиента.
- `09-files-new-product` — создание продукции.
- `10-files-new-event-timer` — создание события-таймера.
- `11-files-new-event-weight-check` — верх формы события «Проверка веса».
- `11b-files-new-event-weight-check-bottom` — низ той же формы; только телефон.
- `12-files-bulk-edit` — массовое изменение выбранных объектов.
- `13-files-product-directories` — папки с продукцией.
- `14-files-products` — список продукции внутри папки.

### Карточки и рецептура

- `15-ingredient-card` — карточка ингредиента.
- `16-event-card-timer` — карточка события-таймера.
- `17-event-card-weight-check` — карточка проверки веса.
- `18-product-card` — полная карточка продукции с рецептурой.
- `19-product-add-ingredient` — добавление ингредиента в рецепт.
- `20-product-add-event` — добавление события в рецепт.
- `21-product-add-linked-action` — добавление связанного действия.

### Администрирование

- `22-roles-system` — системная роль Administrator.
- `23-roles-custom` — полная матрица прав обычной роли.
- `24-roles-create` — создание роли.
- `25-users` — список пользователей.
- `26-users-create` — создание пользователя.
- `27-users-roles` — назначение ролей пользователю.

### Заявки и выполнение

- `28-orders-bun-active` — активные заявки булочного цеха.
- `29-orders-bun-history` — история заявок булочного цеха.
- `30-orders-upload` — загрузка заявки из файла.
- `31-orders-create` — ручное создание заявки.
- `32-orders-unassigned-active` — активные нераспределённые заявки.
- `33-orders-unassigned-history` — история нераспределённых заявок.
- `34-orders-bread-active` — активные заявки хлебного цеха.
- `35-order-active-detail` — карточка активной заявки.
- `36-order-add-product` — добавление продукции в заявку.
- `37-order-force-complete` — подтверждение принудительного завершения.
- `38-order-archive-detail` — карточка архивной заявки с позицией.
- `39-order-history` — история изменений заявки.
- `40-current-order-empty` — текущая заявка в реальном пустом состоянии.
- `41-current-order-selection` — ручной выбор актуальной заявки.
- `42-execution-empty` — очередь выполнения в реальном пустом состоянии.

На дату съёмки активной текущей заявки не было, поэтому экраны `40` и `42` показывают предусмотренное интерфейсом пустое состояние. Архивная заявка с данными вынесена в `38` и `39`.
